# Arc/Circle/Encode brief

AgentPay Guard is an Agentic Economy proof for deterministic policy before autonomous USDC spend. Its primary scenario is an x402-style paid API micropayment: recipient, amount, daily budget, per-request limit, velocity, rules, audit record, receipt, then an explicit future settlement boundary.

The Arc/Circle relevance is the placement of that boundary before a future programmable-money adapter. The implementation does not call Arc, Circle, Circle Gateway, CCTP, or x402 services and does not claim official integration.

CCTP, ERC-20 authority, and Paymaster contexts are deterministic local policy inputs. CitePay is only a secondary local source-selection illustration.
