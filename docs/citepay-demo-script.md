# CitePay local illustration

CitePay is a secondary local source-selection illustration inside AgentPay Guard. It is not a separate product, payment rail, or primary demo path.

Open **Illustrative CitePay source-selection flow** only after the x402 policy proof. The flow selects mock paid-source candidates, maps them to ordinary AgentPay Guard payment intents, and applies the same deterministic policy and audit rules.

No source is purchased. The cards, selection, and amounts are local demo data. An `ALLOW` result still does not execute a payment.
